# 已实施的最小收益重构：网络兜底证据边界

2026-09-06。基于 RECOVERY.md 的结论，不建设完整 DeepSearch，也不启用字段自动补全；只改现有 `metadata_web_fallback` 的确定性边界。

## 复盘与范围

正文组没有额外安全补全收益；真实错误集中在来源/引用和身份判定。能立即确定性修复的不是“让 LLM 更聪明”，而是禁止模型绕过现有候选及数据契约。

1. **先过滤再停搜**：搜索结果先按 URL 注册表重建 source/id、应用频道白名单，再决定是否停止候选查询。外站噪声不再使后续标题变体失去机会；最多仍为三次搜索、一次 judge，不新增模型循环。白名单内但语义无关的词典页仍需 judge 判断，本次不声称解决全部搜索相关性。
2. **候选与结果共用边界**：排序后最多五条同时用于 prompt 和出口校验。URL 必须指向实际展示的同一条结果；无 URL 必须有唯一精确 source/id；显式身份冲突、未知页面、仅标题的 found=true 均拒绝。注册表解析值是身份依据，不信任搜索结果/模型自报的 source。
3. **封住结构字段旁路**：保留合法身份，但剥离 episode_list、single_season_entry、alt_external_ids，以及已有的季数/集数禁止字段。拒答清除残留 matched_entity，避免被其他调用者误用。
4. **兼容重试与缓存**：违反证据契约属于可重试错误，不变成永久未找到；使用现有 transient 标记，不新增状态机。缓存代际 5→6，旧判定惰性失效，不能短路新校验。同步更新 prompt，要求复制可见候选，删除已退役来源指令。

## 确定性旧/新对照

用同一组注入的搜索结果和模型结果，对比仓库基准 `5f456351c7cf1c8ac319e773f286bd958d31f6f7` 的模块与工作区新模块；不联网、不落库。它们是受控契约反例，不是新增真实作品准确率。

| 反例 | 旧实现 | 新实现 |
|---|---|---|
| 第一次只有外站噪声、第二次有合法身份 | 搜索一次即停止，found=false | 搜索第二次，返回合法 bangumi:1 |
| 展示 subject/1，模型返回未展示 subject/999 | found=true，接受999 | found=false＋可重试错误，不输出错误身份 |
| 合法身份夹带 episode_list=50、单季证据及额外身份 | 全部透传 | 身份仍命中，三个未授权字段均移除 |

对应自动化回归在 `tests/unit/test_metadata_fallback_grounding.py`，另覆盖 URL/source/id 冲突、第六条不可见候选、后续搜索异常保留 transient。旧的“任意生成 URL 也成功”测试已改为必须给出真实候选，而不是保留错误契约。

## 验证与边界

- metadata fallback/agent/Bangumi/registry 单元测试＋完整 corpus 回归：**1,150 passed**（一个现有 pytest-asyncio 弃用警告）。
- Ruff 与 `git diff --check` 通过。
- 两个真实标题的只读在线复查（`refactor-check/baseline/`）：Kozame S2 仍 found=true、身份 `anilist:204269`、无 source error；Zeztz 仍 found=false、无 source error。两次均无外层执行异常。这验证合法命中未被新边界误拒，不是两样本准确率提升声明，也不替代固定证据三轮实验。
- 使用 `code-review-and-quality` 的跨模型审查；无阻断问题，已采纳 prompt 契约同步意见。
- 无数据库迁移、无生产记录重绑、无服务部署或重启。代际变更只在新代码运行并读取缓存时生效；存量错误作品不会自动修复。
- **未解决** Ultraman 在 Bangumi 主源内部被选成同系列另一作品、Shazam 正文表格错归属，以及弱来源字段的语义证明。候选绑定只能证明“确实选择了提供的候选”，不能证明“选对了作品”。这些仍需隔离实验，不把本次护栏包装成完整 DeepSearch 增益。

后续若推进主源身份验证，应先定义不误伤跨语言别名、绝对集号、多季包的矛盾条件，并用独立留出集验证。不要用标题弱相似或包内集号大于条目集数直接全局拒绝作品。
