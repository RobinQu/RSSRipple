# V31 元数据刷新弹窗国际化（P1-F1，现 P2）

## 必要性与范围

当前 main 的 WorkMetadataRefreshModal 自有标题、按钮、表头、人工保护提示和操作消息硬编码中文，SeriesDetail/MovieDetail 共用该组件。真实 Chromium 在 localStorage=en-US 时实际标题仍为“搜索并刷新元数据”，英文断言失败（a/b 退出 1）。这是英文界面的功能说明缺陷，保留 P2，不声称数据损坏或后端故障。

方案复用 useTranslation 与现有 zh-CN/en-US 资源及单大括号插值配置；公共搜索/操作表头复用 common，组件专有文字放 metadataRefresh。英文更新数量区分 one/other，中文保持原表达。作品标题、原始字段值、来源标识、服务端错误正文不翻译，不改变搜索、人工覆盖、预览或应用载荷。无新依赖。
