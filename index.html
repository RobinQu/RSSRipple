RSSRipple

An RSS subscription downloader for TV / anime / movie releases.
从订阅到下载，一条流水线闭环。

Fetch→Parse→Match→Filter→Download

Highlights

  • Incremental agent runs with a watermark — history is never silently re-dispatched
  • LLM proposes feed field-mapping rules; refine them in the UI before saving
  • Unified metadata agent cleans titles, infers season/episode, caches results locally
  • Filter DSL with nested boolean queries, per-work overrides, batch & subtitle support
  • Multiple Transmission instances, per-agent subdirectories, live progress sync
  • React dashboard: metrics, downloads, pending decisions, channels & works library

Quick start

# set LLM_API_KEY / LLM_BASE_URL / LLM_MODEL in .env
cp .env.example .env
docker compose up --build
# Web UI → http://localhost:9001
